# Sourccey SFT training

> Status: Internal runbook

Run from the repository root. Set `CUDA_VISIBLE_DEVICES` to the GPU you want to use.

## Start training

```bash
CUDA_VISIBLE_DEVICES=1 \
uv run lerobot-sft \
  --config_path=src/lerobot/scripts/sourccey/train/configs/sft_recipes/shirt_fold_c_010.yaml
```

The recipe's `output_dir` must not already exist when starting a new run.


## Resume training

```bash
CUDA_VISIBLE_DEVICES=1 \
uv run lerobot-sft \
  --resume=true \
  --config_path=outputs/sft/xvla_s_sourccey-shirt-fold-c-009-corners-006/checkpoints/350000/pretrained_model/train_config.json
```

Always resume with the checkpoint's `train_config.json`, not the original recipe.
If no emergency checkpoint was saved, this resumes from the latest periodic checkpoint.
